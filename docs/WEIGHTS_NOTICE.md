# Weight provenance and distribution notice

Original model: NVIDIA `nvidia/mamba2-8b-3t-4k`.

Original model license: Apache-2.0, as declared in the [official pinned model card](https://huggingface.co/nvidia/mamba2-8b-3t-4k/blob/b915550c63ba9359f88f44d1f6a600d85af27302/README.md). A copy of the license is provided in [WEIGHTS_LICENSE.txt](WEIGHTS_LICENSE.txt).

This project modifies the original weights by independent affine INT4 quantization of 114 large matrices with 128-element groups, keeping 393 small tensors in FP16. It adds a separately trained Resurface-inspired adapter after quantization. The original model authors do not endorse these modifications. Published metrics must identify the actual modified checkpoint and evaluation protocol.

The source model authors and paper are credited in the upstream model card: *An Empirical Study of Mamba-based Language Models*, Waleffe et al., 2024, [arXiv 2406.07887](https://arxiv.org/abs/2406.07887).

The independent quantized base weights and this project's independently trained adapter tensors are distributed under **Apache-2.0**. The grant for project contributions is made by EndlessChasing. It covers:

- The final trained adapter at `pretrained/w4_resurface_v1/adapter_fp16.pt`, SHA256 `6d38c24a102cbf83c5f1dfe4362a0b5c5e779e793a27bccd4e592ff6c9de7ca1`.

The framework, quantization code, adapter implementation and training/evaluation scripts are separately distributed under the repository's [GPL-3.0 license](../LICENSE). The Apache-2.0 grant for weight artifacts does not change the code license. No Quamba software or quantized weights are included.

The adapter is an independently implemented post-D variant inspired by [Resurface](https://github.com/Oso1106/Resurface-Multi-Binding-Recall-Is-Latent-in-Mamba-s-State), rather than an exact reproduction of its original insertion site. It is trained for this specific W4 base; neither original FP16 adapters nor adapters for other quantizers are interchangeable with it.

## Distribution contents

The small trained adapter is included under `pretrained/`. The approximately 4.381 GB packed base is generated by the reproduction commands and is not included in Git. Availability of source code and an adapter should not be described as publication of the complete packed base.

When redistributing a standalone quantized model bundle, include this provenance notice, [WEIGHTS_LICENSE.txt](WEIGHTS_LICENSE.txt), any applicable upstream notices, the exact source/quantization manifest and the matching adapter notice. Place the license and notices at the outer bundle level, beside the unmodified W4 package directory. Retain original attributions and this modification notice. The pinned upstream repository contains no separate NOTICE file.

The reported 4,381,415,300-byte core base total counts 507 tensor files plus its bound manifest. Outer license documents, provenance notices, tokenizer and adapter are separate bytes. Keep the core files and manifest unchanged so their identities remain valid.
